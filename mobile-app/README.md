# SurgicGuide Mobile

Cross-platform iOS/Android prototype for the hypothetical SurgicGuide Limited project.

## Run locally

1. Install Node.js.
2. From this folder run `npm install`.
3. Run `npx expo start`.
4. Open the project with Expo Go on a compatible device, or launch an iOS/Android simulator.

## Product status

This is an educational and illustrative prototype. SurgicGuide Limited and the AI-integrated FLIM System are hypothetical. The app is not a medical device and must not be used for diagnosis, treatment, surgical guidance or clinical decision-making.

## Structure

The prototype is intentionally dependency-light. `App.js` contains the initial navigation, visual system and content screens. Future iterations can split screens/components into separate files, add local assets, full references, richer scientific figures and an explicitly simulated FLIM demonstration.
