# Version 1.0 Release Notes

SurgicGuide Mobile is the companion educational app for the hypothetical SurgicGuide Limited project.

Version 1.0 includes the AI-integrated FLIM System overview, specialist and non-specialist FLIM science content, 28 scientific references, the SurgicGuide team, and a clearly labelled simulated FLIM viewer.

The simulated viewer contains illustrative data only. SurgicGuide Limited and the AI-integrated FLIM System are hypothetical. This app is not a medical device and is not intended for diagnosis, treatment, surgical guidance or clinical decision-making.
